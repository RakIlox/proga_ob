# 📄 PDF Appender

**Простое приложение для добавления одной и той же PDF-страницы в конец множества файлов.**

Идеально подходит для массового добавления подписей, титульных листов, квитанций об оплате или любой другой стандартной страницы в конец большого количества PDF-документов.

---

## 🚀 Возможности

- 📂 Выбор папки с исходными PDF-файлами.
- 📄 Выбор одного PDF-файла, который будет добавлен в конец каждого документа.
- 📁 Выбор папки для сохранения результатов (оригиналы не изменяются!).
- 🖥️ Удобный графический интерфейс.
- 📊 Прогресс-бар и лог операций.
- ⚡ Многопоточная обработка – интерфейс не зависает.

## 🛡️ Важно! Ложные срабатывания антивируса

Некоторые антивирусные программы могут помечать файл `PDFAppender.exe` как подозрительный. 

**Это ложное срабатывание!**

Причины:
- Программа собрана с помощью утилиты **PyInstaller**, которая упаковывает Python-код и интерпретатор в один .exe-файл.
- Многие антивирусы считают такую упаковку подозрительной, потому что её часто используют вирусописатели для обхода обнаружения.
- В коде программы **нет ничего вредоносного** – он только открывает PDF, добавляет страницы и сохраняет их.

### Как обойти блокировку:

1. **Добавьте файл в исключения антивируса** (инструкции для разных антивирусов можно найти в интернете).
2. **Запустите программу в изолированной среде** (например, Windows Sandbox), чтобы убедиться в её безопасности.
3. **Либо используйте исходный код** (см. раздел "Запуск из исходного кода").

Программа:
- ❌ Не требует доступа в интернет.
- ❌ Не собирает никаких данных.
- ❌ Не изменяет оригинальные файлы (все результаты сохраняются в отдельную папку).
- ✅ Работает только с выбранными пользователем файлами.
